## 🏗️ System Architecture & Technologies (โครงสร้างระบบและเทคโนโลยีที่ใช้)

แอปพลิเคชันนี้พัฒนาด้วย **Kotlin** และใช้เทคโนโลยีที่ทันสมัยของ Android (Modern Android Development - MAD) โดยมีโครงสร้างหลักดังนี้:

### 1. สถาปัตยกรรม (Architecture)
- **MVVM (Model-View-ViewModel):** 
  - ช่วยแยกส่วนจัดการข้อมูล (Data) ออกจากการแสดงผล (UI) อย่างชัดเจน 
  - ทำให้โค้ดอ่านง่าย ทดสอบได้ง่าย (Testable) และดูแลรักษาง่าย (Maintainable)
- **Repository Pattern:** ใช้เป็นตัวกลางระหว่าง ViewModel และแหล่งข้อมูล (เช่น Database) เพื่อจัดการ logic ในการดึงและบันทึกข้อมูล

### 2. เทคโนโลยีที่ใช้ (Tech Stack)
- **UI Framework:** ใช้ **Jetpack Compose** (Declarative UI) ซึ่งเป็นเครื่องมือสร้าง UI ล่าสุดของ Android ช่วยให้สร้างหน้าจอได้รวดเร็ว ลดการเขียนโค้ด XML ที่ซับซ้อน
- **Local Database:** ใช้ **Room Database** ซึ่งเป็น Abstraction Layer ครอบ SQLite ช่วยให้จัดการฐานข้อมูลในเครื่อง (Local Storage) ได้อย่างปลอดภัยและง่ายดาย (เช่น เก็บข้อมูลท่าออกกำลังกายและประวัติการเล่น)
- **Asynchronous Programming:** ใช้ **Kotlin Coroutines** และ **Flow** สำหรับการจัดการงานที่ทำงานอยู่เบื้องหลัง (Background Tasks) เช่น การอ่าน/เขียนฐานข้อมูล หรือการนับเวลาถอยหลัง (Timer) แบบเรียลไทม์
- **Navigation:** ใช้ **Jetpack Compose Navigation** สำหรับการจัดการเปลี่ยนหน้าจอ (Routing) ภายในแอปพลิเคชัน

### 3. โครงสร้างโฟลเดอร์ (Folder Structure)
- `data/`: เก็บโค้ดที่เกี่ยวกับฐานข้อมูล (Room), Entity Models, DAOs และ Repositories
- `ui/`: เก็บโค้ด Jetpack Compose แบ่งย่อยเป็น `screens` (หน้าจอต่างๆ), `theme` (สี, ฟอนต์), และ `viewmodel` (ส่วนจัดการ Logic ของ UI)
- `navigation/`: จัดการเส้นทางการนำทางระหว่างหน้าจอต่างๆ

## 🌟 Core Features (ฟีเจอร์หลัก)

### 1. เพิ่มท่าออกกำลังกาย
ผู้ใช้สามารถกำหนด:
- ชื่อท่าออกกำลังกาย
- จำนวนเซ็ท
- จำนวนครั้งต่อเซ็ท (Reps)
- เวลาพัก (วินาที)

**Preset ที่มีให้เลือก:**
- Beginner: 3x10 พัก 60 วินาที
- Strength: 5x5 พัก 180 วินาที

### 2. หน้านับเซ็ท (Workout Screen)
- แสดงชื่อท่า, เซ็ทปัจจุบัน (เช่น Set 2 / 4) และจำนวนครั้ง (Reps)
- มีปุ่ม **“เสร็จแล้ว”** เมื่อกดปุ่มจะทำการ:
  - เพิ่มเซ็ทอัตโนมัติ
  - เข้าสู่โหมดพัก
  - เริ่มนับเวลาพักทันที

### 3. ระบบพัก (Rest Timer)
- Countdown Timer นับถอยหลังเวลาพัก
- ปุ่ม +10 / -10 วินาที เพื่อปรับเวลาตามต้องการ
- ปุ่มข้ามพัก (Skip Rest)
- แจ้งเตือนเมื่อพักครบ (เสียง / สั่น / Notification)

### 4. เมื่อทำครบทุกเซ็ท
- แสดงสถานะ **Completed**
- ตัวเลือกหลังจากทำเสร็จ:
  - เล่นท่าเดิมใหม่
  - ไปท่าถัดไป
  - จบการออกกำลังกาย

## 🚀 Features เสริม (ในอนาคต)

- **Workout Summary:** สรุปจำนวนท่าที่เล่น, จำนวนเซ็ทรวม, เวลาที่ใช้ทั้งหมด, และเวลาพักรวม
- **History / Log:** ดูประวัติการออกกำลังกาย และดูการพัฒนาของแต่ละท่า
- **Smart Rest:** ปรับเวลาพักอัตโนมัติตามความหนักของเซ็ท และแนะนำการพักเพิ่มในเซ็ทท้ายๆ

## 📱 User Flow (การใช้งานเบื้องต้น)
1. เปิดแอพ
2. เพิ่มท่าออกกำลังกาย
3. เริ่มออกกำลังกาย
4. ทำเซ็ท → กดปุ่ม **"เสร็จ"**
5. เข้าสู่ช่วงพักอัตโนมัติ
6. ทำวนไปจนครบเซ็ท
7. ดูสรุปผลการออกกำลังกาย
